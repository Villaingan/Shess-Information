Sonderzug

Die Umwandlung

Erreicht ein Bauer die letzte Reihe auf der gegenüberliegenden Seite des Brettes, wird er sofort umgewandelt. Der Bauer wird durch eine Dame, einen Turm, einen Läufer oder einen Springer derselben Farbe ersetzt.

Welche Figur ist möglich?

Meist wird eine Dame gewählt, weil sie besonders beweglich ist. Eine Umwandlung in eine andere Figur kann in bestimmten Stellungen aber vorteilhaft sein. Die Wahl ist unabhängig davon, welche eigenen Figuren zuvor geschlagen wurden; man kann also auch mehrere Damen haben.
